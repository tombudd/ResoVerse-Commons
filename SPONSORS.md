# Sponsor ResoVerse Commons

ResoVerse Commons is independent open-source infrastructure for inspecting and
reviewing governed capability candidates before execution. Sponsorship helps
fund specification work, conformance fixtures, reference implementations,
documentation, maintenance, and distinct technical review.

## Sponsor routes

### GitHub Sponsors

The repository is configured for GitHub Sponsors under `tombudd`. The receiving
profile must complete GitHub's identity, tax, payout, tier, and approval process
before GitHub can accept payments. When that profile becomes active, GitHub will
display the repository's Sponsor button without another funding-file change.

### Organizational sponsorship

Organizations interested in funding a public interoperability milestone,
conformance work, documentation, or independent review can contact
[Tom Budd](mailto:tom@tombudd.com?subject=ResoVerse%20Commons%20sponsorship).
Any scope, deliverable, attribution, and conflict boundary must be agreed in
writing before work begins.

## Sponsorship boundary

Sponsorship supports the work; it does not buy:

- a validator `PASS`, candidate admission, or production activation;
- control over technical or governance decisions;
- access to private systems, data, credentials, or research;
- suppression of defects, limitations, `HOLD` outcomes, or independent review;
- endorsement of a sponsor's product or claims.

Sponsor recognition is opt-in. Material sponsorships and conflicts should be
disclosed where they could reasonably affect a contribution or review.

## Suggested GitHub Sponsors tiers

These are drafts for the account onboarding screen, not active offers:

- **Supporter — $5/month:** sponsor badge and public project updates.
- **Builder — $25/month:** Supporter benefits and optional name recognition.
- **Sustainer — $100/month:** Builder benefits and a quarterly group briefing.
- **Institutional — $500/month:** optional organization recognition and a
  quarterly public roadmap briefing; no private authority or preferential
  acceptance.
- **One-time support:** $10, $50, or $250 for people who prefer not to subscribe.

Benefits should remain scalable, public-boundary safe, and independent of
acceptance decisions.

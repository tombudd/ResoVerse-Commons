# Maintainers and Registry Trust

V1 begins with Founder stewardship by Tom Budd. This file records the intended
trust contract; it does not publish signing keys or establish a production
registry.

Before signed registry releases begin, the project must define:

- maintainer and reviewer identities;
- release-signing and verification instructions;
- immutable version identifiers and compatibility ranges;
- revocation, suspension, deprecation, and appeal procedures;
- vulnerability response and maintainer succession;
- an append-only history of registry state changes.

A maintainer may not provide the independent review of their own contribution.
